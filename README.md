# MandelbrotSetShader
A shader art exercise exploring the **Mandelbrot set** using fragment shaders.

## Introduction
During the process of designing a shader I felt inclined to implement a fractal figure. In the end I choose to plasm the Mandelbrot set, wich is one of the most famous fractals among mathematicians.
Inside this repository there are two versions of the fragment shader.
```
/mandelbrotSetShader.frag
/mandelbrotSetShaderLegibleVersion.frag
```
The first one is the light version of the code that weights less than **512 bytes**. The other one is a more legible version made for better understanding of the code.
